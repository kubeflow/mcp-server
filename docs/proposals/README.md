# MCP Server Enhancement Proposals

KEPs document significant changes to the project's scope, architecture, or public interfaces.
Use the [Kubeflow community KEP guidance](https://github.com/kubeflow/community/blob/master/proposals/README.md)
for the shared process.

## Adding a Proposal

1. Copy [NNNN-template](NNNN-template/README.md) to
   `docs/proposals/<issue-number>-<short-title>/`, using the MCP Server tracking issue number.
2. Describe the motivation, scope, design, validation, and graduation criteria. Keep supporting
   documents in the same directory.
3. Add the proposal to the list above and request review from maintainers and affected component owners.
